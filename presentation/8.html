Module Functionality

Recruitment Management System

Applicant-scoped Functions

  • View settings
  • Upload resume
  • Receive notifications
  • Update settings
  • Search job listings
  • View Testimonials
  • View About Page
  • Update profile/password
  • View job listings
  • Apply for vacancy

Recruiter-scoped Functions

  • Set job vacancies
  • View applicants
  • View account settings
  • Edit job vacancies
  • View resume of applicant
  • Change account settings
  • Set job description
  • Hire applicants
  • Update profile/password
  • Register account
  • Filter resumes by type

Admin-scoped Functions

  • Add Recruiters
  • Remove Recruiters
  • Create contact pages
  • Set about pages
  • Change password
  • View Recruiter List
Note: Admin cannot enable or disable recruiter accounts.
